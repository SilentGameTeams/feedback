# Silent Game Feedback

المركز المركزي لملاحظات Silent Game: تقارير الأخطاء، وطلبات الميزات، وأسئلة الاستخدام، والاستفسارات حول المشاريع.

**[مدخل الملاحظات](https://silentgameteams.github.io/feedback/)** — انقر هنا لإرسال ملاحظاتك.

## النطاق ومسارات الإرسال

### 1. المشاريع غير التابعة لـ Silent Game

قد لا تكون بعض مشاريع SilentStudio مسجلة بعد. أرسل ملاحظاتك عبر قناة الملاحظات الخاصة بـ SilentStudio-CN؛ وإذا لم يكن هناك مستودع مخصص بعد، راسل SilentStudio@Home.email.cn. لا يمكننا ضمان الرد على كل رسالة.

### 2. مشاريع Silent Game التي لا تملك مجلدًا مخصصًا

افتح issue في هذا المستودع واذكر اسم المشروع والإصدار أو commit في بداية العنوان أو النص.

### 3. المشاريع المسجلة

تحتوي المشاريع المسجلة على مجلد بالاسم نفسه في جذر المستودع. هذا المجلد هو نقطة الملاحظات الافتراضية للمشروع. المجلدات الأربعة التالية هي البنية القياسية:

- language: الترجمة والمصطلحات والتعريب
- bug: عيوب البرنامج أو الخدمة
- feature: طلبات الميزات والتحسينات
- question: أسئلة الاستخدام والاستفسارات

قد لا يملك المشروع كل المجلدات القياسية، وقد يضيف مجلدات خاصة به. تحقق من مجلد المشروع الفعلي قبل النشر. اذكر اسم المشروع والفئة في issue، مثل [project][bug].

## قبل فتح issue

- ابحث أولاً عن issues موجودة.
- اذكر المشروع والإصدار أو commit ونظام التشغيل والبنية.
- اذكر خطوات إعادة الإنتاج والنتيجة المتوقعة والفعلية.
- أرفق السجلات أو لقطات الشاشة ذات الصلة؛ لا تضمّن أسرارًا أو بيانات شخصية.
- لا تنشر ثغرات الأمان علنًا. راسل SilentStudio@feedback.email.cn.
- لا تنشر تفاصيل اختبار غير مصرح به أو محتوى مسيئًا.

## الاستجابة

- تُعالج الملاحظات حسب الأولوية؛ لا يوجد SLA ثابت.
- تُعالج تقارير الأمان وفق سياسة الصيانة والأمان في Silent Game.
- لن يُلاحق المبلّغون حسن النية.
