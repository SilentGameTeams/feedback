# Silent Game Feedback

Pintu masuk umpan balik utama Silent Game: laporan bug, permintaan fitur, pertanyaan penggunaan, dan pertanyaan tentang proyek.

**[Pintu masuk umpan balik](https://silentgameteams.github.io/feedback/)** — Klik di sini untuk mengirim umpan balik.

## Cakupan dan jalur pengiriman

### 1. Proyek di luar Silent Game

Beberapa proyek SilentStudio mungkin belum terdaftar. Kirim umpan balik melalui kanal umpan balik SilentStudio-CN; jika belum ada repositori khusus, kirim email ke SilentStudio@Home.email.cn. Kami tidak dapat menjamin balasan untuk setiap pesan.

### 2. Proyek Silent Game tanpa folder khusus

Buka issue di repositori ini dan sebutkan nama proyek, versi, atau commit di awal judul atau isi.

### 3. Proyek terdaftar

Proyek terdaftar memiliki folder dengan nama yang sama di akar repositori. Folder ini adalah pintu masuk umpan balik default proyek. Empat subfolder kategori berikut adalah tata letak standar:

- language: permintaan terjemahan, terminologi, dan lokalisasi
- bug: cacat program atau layanan
- feature: permintaan fitur dan peningkatan
- question: pertanyaan penggunaan dan permintaan

Sebuah proyek mungkin tidak memiliki semua folder standar dan dapat menambahkan folder sendiri. Periksa folder proyek yang sebenarnya sebelum memposting. Sebutkan nama proyek dan kategori dalam issue, misalnya [project][bug].

## Sebelum membuka issue

- Cari issue yang sudah ada terlebih dahulu.
- Sertakan proyek, versi atau commit, sistem operasi, dan arsitektur.
- Sertakan langkah reproduksi, hasil yang diharapkan, dan hasil aktual.
- Lampirkan log atau tangkapan layar yang relevan; jangan sertakan rahasia atau data pribadi.
- Jangan mempublikasikan kerentanan keamanan. Kirim email ke SilentStudio@feedback.email.cn.
- Jangan memposting detail pengujian tanpa izin atau konten yang menyinggung.

## Respons

- Umpan balik ditangani berdasarkan prioritas; tidak ada SLA tetap.
- Laporan keamanan mengikuti kebijakan pemeliharaan dan keamanan Silent Game.
- Pelapor dengan niat baik tidak akan dituntut.
