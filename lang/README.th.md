# Silent Game Feedback

ช่องทางรวมสำหรับส่งความคิดเห็นถึง Silent Game: รายงานข้อบกพร่อง คำขอฟีเจอร์ คำถามการใช้งาน และการสอบถามเกี่ยวกับโครงการ

**[ทางเข้าความคิดเห็น](https://silentgameteams.github.io/feedback/)** — คลิกที่นี่เพื่อส่งความคิดเห็น

## ขอบเขตและช่องทางส่ง

### 1. โครงการที่ไม่ได้อยู่ภายใต้ Silent Game

โครงการบางส่วนของ SilentStudio อาจยังไม่ได้ลงทะเบียน โปรดส่งความคิดเห็นผ่านช่องทางของ SilentStudio-CN หากยังไม่มีรีพอซิทอรีเฉพาะ โปรดอีเมลถึง SilentStudio@Home.email.cn เราไม่สามารถรับประกันการตอบกลับทุกข้อความได้

### 2. โครงการ Silent Game ที่ยังไม่มีโฟลเดอร์เฉพาะ

เปิด issue ในรีพอซิทอรีนี้ และระบุชื่อโครงการ เวอร์ชัน หรือ commit ที่จุดเริ่มต้นของหัวข้อหรือเนื้อหา

### 3. โครงการที่ลงทะเบียนแล้ว

โครงการที่ลงทะเบียนแล้วมีโฟลเดอร์ชื่อเดียวกันที่รากของรีพอซิทอรี โฟลเดอร์นี้เป็นช่องทางเริ่มต้นของโครงการ โฟลเดอร์หมวดหมู่สี่โฟลเดอร์ต่อไปนี้เป็นโครงสร้างมาตรฐาน:

- language: คำขอแปล คำศัพท์ และการรองรับภาษา
- bug: ข้อบกพร่องของโปรแกรมหรือบริการ
- feature: คำขอฟีเจอร์และการปรับปรุง
- question: คำถามการใช้งานและการสอบถาม

โครงการอาจไม่มีโฟลเดอร์มาตรฐานครบทุกโฟลเดอร์ และอาจเพิ่มโฟลเดอร์ของตนเอง ตรวจสอบโฟลเดอร์จริงของโครงการก่อนโพสต์ ระบุชื่อโครงการและหมวดหมู่ใน issue เช่น [project][bug]

## ก่อนเปิด issue

- ค้นหา issue ที่มีอยู่ก่อน
- ระบุโครงการ เวอร์ชันหรือ commit ระบบปฏิบัติการ และสถาปัตยกรรม
- ระบุขั้นตอนการทำซ้ำ ผลลัพธ์ที่คาดหวัง และผลลัพธ์จริง
- แนบ log หรือภาพหน้าจอที่เกี่ยวข้อง ห้ามใส่ความลับหรือข้อมูลส่วนบุคคล
- ห้ามเปิดเผยช่องโหว่ด้านความปลอดภัยต่อสาธารณะ โปรดอีเมลถึง SilentStudio@feedback.email.cn
- ห้ามโพสต์รายละเอียดการทดสอบที่ไม่ได้รับอนุญาตหรือเนื้อหาที่ไม่เหมาะสม

## การตอบกลับ

- ความคิดเห็นได้รับการจัดการตามลำดับความสำคัญ ไม่มี SLA ตายตัว
- รายงานด้านความปลอดภัยเป็นไปตามนโยบายการบำรุงรักษาและความปลอดภัยของ Silent Game
- ผู้รายงานโดยสุจริตจะไม่ถูกดำเนินการ
