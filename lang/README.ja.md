# Silent Game Feedback

Silent Game へのフィードバック窓口です。不具合報告、機能要望、使い方の質問、プロジェクトに関する問い合わせを受け付けます。

**[フィードバック入口](https://silentgameteams.github.io/feedback/)** — ここをクリックしてフィードバックを送信してください。

## 対象と提出経路

### 1. Silent Game 以外のプロジェクト

SilentStudio の一部プロジェクトはまだ登録されていない場合があります。SilentStudio-CN のフィードバック窓口から提出してください。専用リポジトリがまだない場合は SilentStudio@Home.email.cn までご連絡ください。すべてのメッセージへの返信は保証できません。

### 2. Silent Game のプロジェクトで専用フォルダがないもの

このリポジトリで issue を作成し、タイトルまたは本文の冒頭にプロジェクト名、バージョンまたは commit を明記してください。

### 3. 登録済みプロジェクト

登録済みプロジェクトにはリポジトリ直下に同名フォルダがあります。このフォルダが既定のフィードバック窓口です。次の 4 つのカテゴリフォルダが標準構成です。

- language: 翻訳、用語、ローカライズの要望
- bug: プログラムまたはサービスの不具合
- feature: 機能要望と改善
- question: 使い方の質問と問い合わせ

プロジェクトによっては標準フォルダがない場合や、独自フォルダを追加している場合があります。投稿前に実際のプロジェクトフォルダを確認してください。issue にはプロジェクト名とカテゴリを明記してください（例: [project][bug]）。

## issue を作成する前に

- 既存の issue を検索してください。
- プロジェクト、バージョンまたは commit、OS、アーキテクチャを記載してください。
- 再現手順、期待する結果、実際の結果を記載してください。
- 必要に応じてログやスクリーンショットを添付してください。秘密情報や個人データは含めないでください。
- セキュリティ脆弱性は公開せず、SilentStudio@feedback.email.cn までご連絡ください。
- 未許可のテスト詳細や攻撃的な内容を投稿しないでください。

## 対応

- フィードバックは優先度順に対応します。固定の SLA はありません。
- セキュリティ報告は Silent Game の保守・セキュリティポリシーに従います。
- 善意の報告者を追及しません。
