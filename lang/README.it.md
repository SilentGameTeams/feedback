# Silent Game Feedback

Punto centrale di feedback per Silent Game: segnalazioni di bug, richieste di funzionalità, domande d'uso e richieste sui progetti.

**[Ingresso feedback](https://silentgameteams.github.io/feedback/)** — Clicca qui per inviare feedback.

## Ambito e percorsi di invio

### 1. Progetti non appartenenti a Silent Game

Alcuni progetti SilentStudio potrebbero non essere ancora registrati. Invia il feedback tramite il canale di feedback di SilentStudio-CN; se non esiste ancora un repository dedicato, scrivi a SilentStudio@Home.email.cn. Non possiamo garantire una risposta a ogni messaggio.

### 2. Progetti Silent Game senza cartella dedicata

Apri una issue in questo repository e indica il nome del progetto, la versione o il commit all'inizio del titolo o del corpo.

### 3. Progetti registrati

I progetti registrati hanno una cartella nella radice del repository. Questa cartella è il punto di ingresso predefinito del feedback del progetto. Le seguenti quattro sottocartelle di categoria costituiscono il layout standard:

- language: traduzione, terminologia e localizzazione
- bug: difetti del programma o del servizio
- feature: richieste di funzionalità e miglioramenti
- question: domande d'uso e richieste

Un progetto potrebbe non avere tutte le cartelle standard e potrebbe aggiungerne altre. Controlla la cartella reale del progetto prima di pubblicare. Indica progetto e categoria nella issue, ad esempio [project][bug].

## Prima di aprire una issue

- Cerca prima issue esistenti.
- Includi progetto, versione o commit, sistema operativo e architettura.
- Includi i passaggi di riproduzione, il risultato atteso e quello reale.
- Allega log o screenshot pertinenti; non includere segreti o dati personali.
- Non pubblicare vulnerabilità di sicurezza. Scrivi a SilentStudio@feedback.email.cn.
- Non pubblicare dettagli di test non autorizzati o contenuti offensivi.

## Risposta

- Il feedback viene gestito per priorità; nessun SLA fisso.
- Le segnalazioni di sicurezza seguono la politica di manutenzione e sicurezza di Silent Game.
- I segnalatori in buona fede non saranno perseguiti.
