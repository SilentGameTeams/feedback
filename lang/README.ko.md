# Silent Game Feedback

Silent Game에 대한 피드백 창구입니다. 버그 보고, 기능 제안, 사용 질문, 프로젝트 문의를 받습니다.

**[피드백 입구](https://silentgameteams.github.io/feedback/)** — 여기를 클릭하여 피드백을 보내세요.

## 범위 및 제출 경로

### 1. Silent Game에 속하지 않는 프로젝트

일부 SilentStudio 프로젝트는 아직 등록되지 않았을 수 있습니다. SilentStudio-CN의 피드백 채널로 제출하세요. 전용 저장소가 아직 없다면 SilentStudio@Home.email.cn으로 연락하세요. 모든 메시지에 대한 답변은 보장할 수 없습니다.

### 2. 전용 폴더가 없는 Silent Game 프로젝트

이 저장소에 issue를 열고 제목이나 본문 시작 부분에 프로젝트 이름, 버전 또는 commit을 명시하세요.

### 3. 등록된 프로젝트

등록된 프로젝트는 저장소 루트에 같은 이름의 폴더가 있습니다. 이 폴더가 해당 프로젝트의 기본 피드백 창구입니다. 다음 네 개의 카테고리 폴더가 표준 구성입니다.

- language: 번역, 용어, 현지화 요청
- bug: 프로그램 또는 서비스 결함
- feature: 기능 제안 및 개선
- question: 사용 질문 및 문의

프로젝트에 따라 표준 폴더가 없을 수도 있고 자체 폴더를 추가할 수도 있습니다. 게시 전에 실제 프로젝트 폴더를 확인하세요. issue에 프로젝트 이름과 카테고리를 명시하세요(예: [project][bug]).

## issue를 열기 전에

- 기존 issue를 먼저 검색하세요.
- 프로젝트, 버전 또는 commit, 운영체제, 아키텍처를 포함하세요.
- 재현 단계, 기대 결과, 실제 결과를 포함하세요.
- 필요한 로그나 스크린샷을 첨부하세요. 비밀 정보나 개인 데이터는 포함하지 마세요.
- 보안 취약점은 공개하지 말고 SilentStudio@feedback.email.cn으로 보내세요.
- 무단 테스트 세부 정보나 공격적인 내용을 게시하지 마세요.

## 응답

- 피드백은 우선순위에 따라 처리되며 고정 SLA는 없습니다.
- 보안 보고는 Silent Game의 유지보수 및 보안 정책을 따릅니다.
- 선의의 보고자는 추적하지 않습니다.
